# OBNI / tipo tributário

TCD2 do campo tipo tributário da empresa grava `OBNI.ID`.
IndexType é **desta** definição (descobrir com Q_OBNI). Não assumir um número de outro projeto.
Não usar `OBNI.Code` nem BPL2.TributType.
Se o ID que a planilha pede não existe, cadastrar na tela Definição do tipo tributário **com o ID que a TCD2 já usa**, ou remapear com o cliente.
