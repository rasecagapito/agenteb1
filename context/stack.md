# Stack

- SAP Business One Brasil, HANA.
- Carga: HANA Studio (INSERT) + tela Administração / Determinação.
- Geração: Python 3 (pandas, openpyxl, pyyaml) em `scripts/`.
- Leitura: gerador de consultas B1.
- Harness: qualquer um que leia `AGENTS.md` (`providers/registry.md`).

Não depende do Portal de Automação B1 nem de um CompanyDB de laboratório. Hierarquia TCD vale; IDs não.
