# Procedimento: WRAPUP

1. Hora real (PowerShell `Get-Date -Format 'yyyy-MM-dd HH:mm'`).
2. History no **repo do projeto cliente**: `memory/history/YYYY-MM-DD-HHMM-sessao.md` (projeto.nome, provedor, decisões, COUNT observados, pendências).
3. Learning só se for reutilizável; se for, também promover via `evoluir.md`.
4. Handoff do mestre: `memory/handoff.md` (substituir, não acumular).
5. Se a carga do cliente fechou: correr `evoluir.md`.

Não gravar INSERT/COUNT que não foram observados.
